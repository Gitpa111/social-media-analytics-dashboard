# PulseBoard — Social Media Analytics Dashboard

A responsive analytics dashboard concept for visualising content performance across Instagram, TikTok and YouTube.

## Features

- Platform and date-range filters
- Dynamic KPI cards
- Interactive reach chart
- Platform-share visualisation
- Top-content performance view
- Campaign performance cards
- Audience age and location insights
- Dark mode with saved preference
- Responsive mobile navigation
- No framework or build process required

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## Portfolio context

This public demo shows front-end development, data visualisation, UI/UX thinking and social media analytics presentation. All figures are illustrative sample data.
